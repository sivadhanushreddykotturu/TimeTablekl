Connect GitHub

Paste a fine-grained token for the TimeTablekl repo with Contents: read and write. It is saved only in this browser.

How do I make the token?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → TimeTablekl.
  3. Permissions → Repository → Contents: Read and write (nothing else).
  4. Set an expiry (for example 90 days), generate, copy it here.
